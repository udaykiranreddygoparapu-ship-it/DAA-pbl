    📚 Design & Analysis of Algorithms: Theoretical Complexity Matrix

    Comparative analysis of the algorithmic paradigms implemented in the Disaster Response Logistics Optimization Platform:

    Algorithm Algorithmic Paradigm Time Complexity Space Complexity Emergency Logistics Application
    Dijkstra's Algorithm Graph Theory / Greedy O((V + E) log V) O(V + E) Emergency dispatch & casualty evacuation routing around blocked roads and landslides.
    Kruskal's Algorithm Greedy / DSU O(E log E) O(V + E) Post-earthquake road reconnection backbone; reconnecting isolated clusters at minimum repair cost.
    Prim's Algorithm Greedy / Cut-Property O(E log V) O(V + E) Depot-centric grid expansion outwards from central logistics hubs with continuous chain of custody.
    0/1 Knapsack Dynamic Programming O(N · W) O(N · W) Optimizing air and truck cargo manifests to maximize survival utility within strict payload limits.
    Greedy Resource Allocation Greedy Heuristic O(D log D + D · R) O(R) Multi-commodity rationing (food, potable water, medical trauma kits) based on casualty triage ranks.
    Red-Black Tree Self-Balancing BST O(log N) per operation O(N) Real-time priority indexing of dynamic shelter requests with guaranteed logarithmic balance.
